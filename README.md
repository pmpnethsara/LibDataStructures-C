# libdatastructures-c

A lightweight and generic **data structures library written in C**.

The goal of this project is to implement common data structures from scratch while keeping the library reusable, modular, and easy to understand.

## Features

* Generic data structures using C
* Dynamic memory allocation
* Modular `.h` and `.c` files
* Function-pointer based operations
* Easy-to-use API
* Focus on clean and reusable C code

## Data Structures

Currently implemented:

* [x] Linked List
* [x] Doubly Linked List
* [ ] Queue
* [ ] Stack
* [ ] Circular Linked List
* [ ] Binary Search Tree
* [ ] Heap
* [ ] Hash Table
* [ ] Graph


## Goals

The long-term goal is to build a reusable C library containing fundamental data structures and algorithms.

The project will focus on:

1. Correct implementations
2. Memory safety
3. Time and space complexity
4. Generic data handling
5. Modular design
6. Testing
7. Clean C programming practices

## Learning Objectives

This project is also intended to strengthen understanding of:

* Pointers
* Structures
* Dynamic memory allocation
* Function pointers
* `void *`
* Header files
* Header guards
* Modular programming
* Data structures
* Algorithms
* Memory management
